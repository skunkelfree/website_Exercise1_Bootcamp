# Beautiful Digital People

**Live Preview:** https://skunkelfree.github.io/website_Exercise1_Bootcamp/

A Next.js website with dynamic hero video, Ken Burns image effects, hover animations, and ambient soundscape.

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deploy

Pushes to `main` automatically deploy to GitHub Pages via GitHub Actions.
